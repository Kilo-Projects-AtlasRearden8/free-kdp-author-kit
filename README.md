# Free KDP Author Kit

A friendly, free directory of official Kindle Direct Publishing (KDP) resources for authors: cover templates, blurb (book description) help, category pickers, and royalty calculators.

## What's inside

| Category | What it is |
|---|---|
| **Cover templates** | Free official KDP cover templates and cover guidelines for paperbacks and eBooks |
| **Blurb writers** | Official KDP guidance for writing your book description (blurb) |
| **Category pickers** | Official Amazon Kindle Store categories to help you pick the right ones |
| **Royalty calculators** | Official KDP royalty information so you know what you'll earn |

## How to use

Open `index.html` in any web browser. Use the search box to filter by name, category, or tag. Click a category chip to see only that type of resource. Click "Open official page" to visit the Amazon/KDP page in a new tab.

No build step, no install, and no internet required after the page loads (the official links themselves open live Amazon pages).

## Official links only

Every link in this directory points to an official Amazon or KDP domain (`amazon.com`, `kdp.amazon.com`, `authorcentral.amazon.com`, `kindlecreate.amazon.com`). No third-party directories, no affiliate links, no paid tools.
